# Task 2: AI-Powered No-Code Website
**Internship Track:** Prompt Engineering (Future Interns)

### 📌 Project Overview
This repository documents **Task 2**, which required building a fully functional, AI-integrated portfolio website using a No-Code tool. I utilized **Framer AI** to generate the design, layout, and copy through advanced prompting.
